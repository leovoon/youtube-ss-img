Extension architecture target

How this prototype maps to the current Chrome extension.

Content script (already partly exists):
  find YouTube video element
  read caption window DOM
  draw video to canvas
  overlay caption text at matching position
  return image blob/dataURL + metadata:
    time, caption text, caption rect, video id

Side panel / popup:
  capture current frame
  auto-capture interval
  queue frames locally
  classify frame type:
    keyframe | subtitle-band
  render:
    LineStack (subtitle-preserving)
    Collage (grid/masonry/strip)

Background service worker:
  keyboard command
  open side panel
  relay messages between popup/content script

Why this flow

The current project already captures YouTube frames and visible captions, then exports vertical collages. The revamp should keep that foundation but add a second export mode: LineStack, where each non-keyframe is cropped to the subtitle area. The editor’s main new interaction is classifying frames and tuning subtitle crop.

Important: keep everything local. The LineStack reference page also emphasizes “no uploads / runs locally,” which fits a Chrome extension well.
