Distilled LineStack tool-section logic

The source page is a Vite SPA. Its bundle reveals a very small, useful algorithm we can adapt directly.

Core idea

LineStack is not a generic collage. It stacks full “keyframe” screenshots with cropped subtitle bands. The subtitle crop slider controls how much of the bottom of each non-keyframe screenshot is retained, so dialogue remains readable while repeated video content is minimized.

For this project: YouTube capture should produce caption-aware frames automatically, then classify frames as keyframe or subtitle band before rendering.
Defaults observed:
MAX_IMAGES = 30
outputWidth = 720 | 1080
bottomKeepRatio = 0.2   // "subtitle crop"
enableKeyframeGap = false
gapSize = 8
background = #FFFFFF
jpgQuality = 0.9
maxPageHeight = { 720: 18000, 1080: 12000 }

For each screenshot:
  scale = outputWidth / naturalWidth
  if keyframe:
    keep source y=0..height
  else:
    keep source bottom band:
      sy = naturalHeight * (1 - bottomKeepRatio)
      sh = naturalHeight * bottomKeepRatio
  draw at width=outputWidth

Then stack top-to-bottom, split huge outputs into pages,
and optionally draw watermark at bottom-right.
